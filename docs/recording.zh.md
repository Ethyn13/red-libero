## 1. 场景包与策略运行数据

| 导出类型 | 操作 | 内容 |
| --- | --- | --- |
| 场景包 | **Save scene** | BDDL、仿真状态、物体和固定设施元数据。 |
| AI 运行数据 | 运行结束后聚焦摄像头并按 **S** | 双摄像头视频、安全标注、HDF5 轨迹和运行元数据。 |

退出 AI 模式前保存运行数据。**Replay** 回放已记录轨迹，不会再次调用模型推理。

## 2. 运行数据目录

```text
datasets/
├── video/<episode>/
│   ├── agentview.mp4
│   ├── eye_in_hand.mp4
│   └── safety_events.json
├── rlds/<episode>.hdf5
└── rlds_annotation/<episode>_info.json
```

输出位于项目根目录的 `datasets/` 下。HDF5 包含动作、仿真状态、观测和运行元数据。目录名 `rlds` 指本项目使用的轨迹格式，并不是 TensorFlow Datasets 的 RLDS 发布格式。

`safety_events.json` 包含活动监控配置、规则结果、诊断信息与触发事件。通过 **Safety rules → Live results → Export events…** 可以单独导出监控信息，不要求处于 AI 运行过程。

## 3. 如何解读结果

任务成功由 BDDL 目标判定，安全规则独立描述违规触发条件。规则初始为真时记录一次触发；条件持续为真不会每个采样都生成新事件。`cumu` 保留已累计的真值采样，直到重置。零事件不表示所有检查都有效，应同时检查 **Unknown** 结果。

<a id="_5"></a>

## 4. 比较实验需要记录什么

保留精确场景包、规则文件、模型权重与版本、归一化键、策略 YAML、运行环境版本、动作和稳定步数预算、渲染后端及项目代码版本。比较 `cumu` 阈值时使用相同模式和采样频率。GUI 适合交互检查，汇总基准指标应使用 RedVLA 批量评测。

数据集、场景、模型权重和本机配置已被 Git 忽略。需要对外分发的实验产物应单独整理发布。
