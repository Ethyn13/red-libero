# 谓词目录

谓词是安全规则树的叶节点，接收场景实体，以及可选的数值阈值或几何部件。逻辑运算符与计数器用于组合这些叶节点，详见[规则树与检测语义](SAFETY_RULES.md)。

下表从 `gui_modules/safety/catalog.py` 自动生成，与规则编辑器使用同一份参数目录。它描述内置谓词的参数约定；具体检测逻辑位于 `libero/libero/envs/predicates/` 和场景对象的状态类中。

## 1. 参数类型

| 类型 | 含义 |
| --- | --- |
| `object` | 精确的场景实体名称或已绑定变量，例如 `?x`。该实体还需要支持所选谓词的状态接口。 |
| `number` | 数值阈值。距离单位为米，力的阈值单位为牛顿。 |
| `robot` | 手臂检测接受的可选机器人占位参数。 |
| `parts` | `all` 或对象接触检测支持的几何部件名称后缀列表。 |

在 GUI 的 **Predicates & objects** 中查看可用名称，在 **Live results** 中查看无法解析的输入。名称存在不代表该实体支持每一种谓词。

## 3. 如何解释结果

这些检测器使用仿真器中的具体判定。特别是，`fall` 使用对象的姿态变化检测，并不是通用的物理跌落定义；`waterfall` 组合对象对的接触与跌落检测。将检测结果作为实验指标前，应在对应资产与任务上验证它的行为。

`notin` 不等于 `(not (in ...))`：前者要求接触与包含关系均不成立。`up` 使用固定的世界坐标高度阈值，而不是相对桌面的高度。距离谓词比较表面距离，边界值也会触发条件。

实体缺失、状态接口不支持或检测异常会产生 **Unknown** 诊断。对未知结果取反不能证明安全。监视器记录已配置的违规条件，不会自动规划修正动作或停止策略。

## 4. 扩展目录

实现检测器并注册名称，在参数目录中补充支持的签名，同时在 `docs/assets/predicates.zh.json` 中添加中文说明。重新构建文档可检查翻译是否完整。参照[贡献指南](contributing.md)，在可控场景中验证条件成立与不成立的情况。
