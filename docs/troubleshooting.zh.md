## 1. GUI 无法打开

激活 GUI 的 Conda 环境后，从 Red-LIBERO 根目录启动。Tk 需要 X11 桌面，`DISPLAY` 必须指向可用的显示会话。仅通过 SSH 登录不会自动创建桌面，远程操作见[远程访问](remote.md)。

如果 Python 导入了其他安装位置，先检查解释器，再安装当前源码：

```bash
which python
python -m pip show red-libero
python -m pip install --no-deps -e .
```

## 2. 渲染或依赖报错

使用[环境安装](installation.md)中的版本，包括 `numpy==1.26.4` 和 `robosuite==1.5.1`。安装系统 OSMesa/OpenGL 库，然后通过 `bash gui_start.sh` 使用默认 CPU 渲染。仅在 EGL 可用且目标 GPU 可以访问时使用 `gui_start_egl.sh`。

请保留源码附带的资产目录。启动器会生成对应当前源码位置的资源配置；从其他机器复制的配置可能包含失效路径。检查 `RED_LIBERO_CONFIG_PATH` 以及兼容变量 `LIBERO_CONFIG_PATH` 的覆盖值。

## 3. 物体或编辑结果不见了

确认当前模式和场景，增删等结构性编辑应在 **Free edit** 中执行。添加物体后，场景重建完成就应显示物体。如果没有出现，检查 GUI 日志中的资产或重建错误，正常操作无需反复刷新。

**Reset** 恢复工作区初始状态，**Resample** 根据 BDDL 约束重新采样。要恢复编辑后的姿态，请打开保存的 BDDL/state 场景包。工具栏 **Save scene** 写入当前工作目录的 `Scene/`，详见[录制与导出](recording.md)。

## 4. 模型服务无法连接

依次检查以下配置：

1. 协议是否正确：RedVLA HTTP 使用 `remote`，OpenPI WebSocket 使用 `openpi`。
2. 地址能否从 GUI 所在机器访问。除非配置了端口转发，否则 GUI 的 `127.0.0.1` 并不是另一台模型服务器。
3. 配置中的解释器、工作目录、模型源码和权重是否存在于实际启动服务的机器上。
4. 查看策略对话框给出的服务日志，处理导入、显存、权重加载或动作归一化错误。
5. 给权重加载留出足够启动时间，然后重新执行 **Check connection**。

`launch.command` 是参数列表，不解释 `&&` 等 shell 运算符。环境激活或多步准备应写入脚本，参见[自定义启动脚本](models.md)。

<a id="_5"></a>

## 5. 模型连接成功但机器人不动

进入 AI policy 只准备运行，点击 **Start run** 才会执行动作。**Start service** 用于启动推理服务，不会开始一轮任务。连接检查可能调用诊断推理，但不会在 GUI 中执行其结果。

如果开始执行后行为异常，检查权重要求的观测、动作维度、归一化键、夹爪约定和任务域。连接成功并不证明权重兼容，接口约定见[连接与配置](POLICY_SERVICES.md)。

## 6. 安全规则出现 Unknown 或没有匹配对象

通过 **Predicates & objects** 选择当前场景中的名称，通过 **Live results** 查看失败原因。对象缺失或谓词接口不支持会产生 Unknown。`exists` 的选择器为空时没有满足条件的对象；`forall` 在空集合上逻辑值为真。解释结果前先检查选择器实际匹配到了什么。

规则描述违规触发条件。结果为真时记录事件，结果为假只表示没有检测到该条件。如果累计条件的触发不符合预期，检查 `cumu` 位于 `exists` 内还是外，以及累计的是成立采样数还是 `rising` 转换次数。[规则语义](SAFETY_RULES.md)包含具体对比。

<a id="_6"></a>

## 7. 文档构建失败

使用独立的 `red-libero-docs` 环境，并在仓库根目录执行命令。安装 `requirements/docs.txt` 后，先严格构建，再运行链接检查器。缺少谓词中文说明或 Markdown 链接失效时，应修正文档。操作步骤见[文档站维护](documentation.md)。

## 8. 提交可复现的问题

提供启动命令、依赖版本、相关日志、移除密钥后的配置文件，以及能复现问题的最小 BDDL/state 场景包。策略行为问题还需说明权重、任务指令、随机种子和动作步数预算，参照[贡献指南](contributing.md)。
